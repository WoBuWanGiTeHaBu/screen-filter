## 第二轮：加亮度滑杆 + 修「黑变灰」

用户反馈两条：①要亮度滑杆；②单层彩色蒙层把纯黑抬灰了，暗部对比度塌。

### 根因（写死在代码注释和 README 里了）

src-over 合成 `out = (1−a)·content + a·color`。`content = 0` 时右边 `a·color` 仍在，
所以**只要蒙层带颜色，黑位必然被抬到 `a × 颜色亮度`**。旧模型墨色 80% 时纯黑被抬到
~104/255，肉眼就是发灰。这是数学性质，调参数解决不了，只能换结构。

### 解法：两层叠加

```
out = (1 − d) · [ (1 − t) · content + t · color ]
```
- 着色层（下层）：颜色 = `HSV(hue, 1−gray/100, 1−0.5·gray/100)`，透明度 `t = 强度/100`。
  **黑位抬升的唯一来源**。
- 压暗层（上层）：纯黑，透明度 `d = 1 − 亮度/100`。纯黑叠加 = 整幅乘系数，
  **黑乘任何数还是黑**，所以压暗完全不伤对比度。

默认档（hue208 / gray20 / strength18 / brightness78）黑位抬升只有 ~18/255；
旧单层模型同色（gray40 / alpha80）是 ~98/255。

### 参数模型变更（旧字段全部作废）

`FilterConfig`：`hue / gray / alpha` → **`hue / gray / strength / brightness`**。
- `strength` = 旧 alpha 改名（着色强度）；`brightness` 新增（100 = 原样，0 = 全黑）。
- 新增派生属性：`tintAlpha` / `dimAlpha` / `tintLayerArgb` / `dimLayerArgb` /
  `blackLift`（黑位抬升估数）/ `liftedBlackColor`。
- sp 键：`K_ALPHA` → `K_STRENGTH` + `K_BRIGHTNESS`；自定义预设 JSON 加了
  `strength` / `brightness` 字段，decode 时兼容读旧的 `alpha`。
- 预设全部按新模型重设（浅 10/94、中 20/84、深 24/62、墨 18/78、暖 16/86）。

### 悬浮窗实现

**单窗口两层**，不是挂两个窗口：一个 `View` + 自绘 `TwoLayerOverlay : Drawable`，
`onDraw` 里连续两次 `canvas.drawColor`（先 tint 后 dim），两次都是 src-over，
正好等于合成式。省掉一整块全屏 GPU layer。
